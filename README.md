- **Real-Time Project Filtering**: Categorized by Systems & Compilers, Backend & Databases, Machine Learning & Vision, and Full Stack Web.
- **Clean Architecture & Design**: Built with responsive semantic HTML5, custom CSS design tokens, glassmorphism, and vanilla JavaScript without heavy frontend framework overhead.
