# Personal Portfolio Website

Welcome to my personal developer portfolio built using React, Vite, Tailwind CSS, and Framer Motion.

## Features
- Modern cyber-theme dark mode aesthetic with glassmorphism and glowing ambient background elements.
- Interactive showcase of full-stack projects, web applications, and system development work.
- Filterable skills dashboard categorized into Programming Languages, Web Development, Databases, Tools, and Core Competencies.
- Smooth scrolling navigation and interactive resume download.

## Technology Stack
- **Frontend Framework**: React 18 + Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: React Icons
- **Deployment**: Vercel

## Local Setup & Development
```bash
# Clone the repository
git clone https://github.com/gaurish676/Portfolio.git
cd Portfolio

# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```
